====================================================
  CIVICPULSE-BRICS — PRESENTATIONS FOLDER
====================================================

PURPOSE:
  This folder stores all pitch deck and presentation files for
  CivicPulse-BRICS. These are used for investor demos, BRICS
  hackathon presentations, and stakeholder briefings.
  Files are generated by scripts in the /scripts folder.

----------------------------------------------------
  FILES IN THIS FOLDER
----------------------------------------------------

1. CivicPulse-BRICS_Pitch_Deck.pptx
   PURPOSE : The full-featured, original pitch deck in editable
             PowerPoint format. Contains all slides with branding,
             architecture diagrams, and feature demos.
   GENERATED BY: scripts/create_presentation_pptx.py

2. CivicPulse-BRICS_Pitch_Deck.pdf
   PURPOSE : PDF export of the full pitch deck. Used for sharing
             where PowerPoint is not available.
   GENERATED FROM: CivicPulse-BRICS_Pitch_Deck.pptx

3. CivicPulse-BRICS_Pitch_Deck_Updated.pdf
   PURPOSE : An updated version of the PDF pitch deck with the
             latest feature additions and branding revisions.

4. CivicPulse-BRICS_Pitch_Deck_Light.pptx
   PURPOSE : A lighter, simplified version of the pitch deck —
             fewer slides, smaller file size. Good for email sharing.
   GENERATED BY: scripts/create_presentation_light.py

5. CivicPulse-BRICS_Pitch_Deck_Light.pdf
   PURPOSE : PDF export of the light version.

6. CivicPulse-BRICS_Pitch_Deck_Light_12Pages.pdf
   PURPOSE : A condensed 12-page summary version of the pitch deck.
             Ideal for quick reads and investor one-pagers.

7. CivicPulse-BRICS_Pitch_Deck_Light_Watermarked.pdf
   PURPOSE : The light pitch deck with a watermark overlay. Used when
             sharing externally with people outside the core team.

====================================================
