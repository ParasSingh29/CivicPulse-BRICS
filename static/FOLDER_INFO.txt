====================================================
  CIVICPULSE-BRICS — STATIC FOLDER
====================================================

PURPOSE:
  This folder serves all front-end assets — HTML pages, JavaScript logic,
  CSS stylesheets, images, and user-uploaded photos. Everything the user
  sees in the browser is served from here.

  STRUCTURE:
    static/
    ├── pages/      HTML pages for each portal role
    ├── js/         JavaScript logic files (one per role)
    ├── css/        Global stylesheet
    ├── img/        Logo images, demo screenshots, sector thumbnails
    └── uploads/    User-uploaded complaint & resolution photos (runtime)

----------------------------------------------------
  static/pages/  — HTML Portal Pages
----------------------------------------------------

1. login.html
   PURPOSE : The landing/authentication page. Contains three login forms:
             Citizen, City Official, and Government Hub. Users enter
             credentials here and are redirected to their respective portal.
   USES    : static/js/login.js, static/js/i18n.js, static/js/app.js
   SERVED BY: server.py route GET /

2. index.html  (inside static/pages/)
   PURPOSE : Alternate entry-point / role-selection splash page for the
             static deployment (e.g., GitHub Pages fallback).
   USES    : static/js/app.js, static/js/i18n.js

3. citizen.html
   PURPOSE : The Citizen Portal dashboard. Includes the sector grid for
             reporting issues, community demand proposal modal, complaint
             history tracker, SLA timeline, map integration, and AI
             voice assistant.
   USES    : static/js/citizen.js, static/js/app.js, static/js/i18n.js
   SERVED BY: server.py route GET /citizen

4. city_official.html
   PURPOSE : The City Official Command Centre. Displays all complaints
             for the official's city, allows status updates, department
             assignment, engineer dispatch, and AI structural plan
             generation.
   USES    : static/js/city_official.js, static/js/app.js, static/js/i18n.js
   SERVED BY: server.py route GET /city-official

5. government.html
   PURPOSE : The Central Government Hub dashboard. Provides a national
             overview of all cities, BRICS collaboration proposals, budget
             allocation, MegaPlan synthesis, and city-level health meters.
   USES    : static/js/government.js, static/js/app.js, static/js/i18n.js
   SERVED BY: server.py route GET /government

6. central_official.html
   PURPOSE : The Central Official portal (subordinate to Government Hub).
             Allows central-level review of city proposals and BRICS
             incoming joint project requests.
   USES    : static/js/central_official.js, static/js/app.js, static/js/i18n.js
   SERVED BY: server.py route GET /central-official

----------------------------------------------------
  static/js/  — JavaScript Logic Files
----------------------------------------------------

1. app.js
   PURPOSE : Shared application bootstrap. Initializes AppState (active
             BRICS node, user session), renders the SVG icon registry,
             handles role switching, BRICS node selector, and shared
             UI utilities (toast notifications, modals).
   USED BY : All HTML pages (loaded first via <script>).

2. i18n.js
   PURPOSE : Internationalisation module. Implements Google Translate
             (GNMT) DOM-based translation engine. Translates all
             data-i18n-tagged elements into the user's selected language.
   USED BY : All HTML pages (loaded second, after app.js).

3. login.js
   PURPOSE : Handles login form submission, credential validation,
             API calls to /api/auth/login, session token storage,
             and post-login redirect to the appropriate portal page.
   USED BY : static/pages/login.html

4. citizen.js
   PURPOSE : The largest JS file. Powers the entire Citizen Portal:
             - Renders sector cards
             - Report Issue modal (complaint form, GPS map, photo upload)
             - Community Demand modal (project proposals, GPS map, voting)
             - Complaint history loader and SLA tracker
             - AI voice assistant (speech-to-text, TTS playback)
             - Location detection (GPS + reverse geocoding)
             - Leaflet.js interactive pin map
   USED BY : static/pages/citizen.html

5. city_official.js
   PURPOSE : Powers the City Official portal:
             - Loads and displays complaints for the city
             - Status update and resolution form
             - AI MegaPlan synthesis trigger
             - City proposal submission to Central Government
             - Complaint filtering and search
   USED BY : static/pages/city_official.html

6. government.js
   PURPOSE : Powers the Government Hub portal:
             - National complaint analytics overview
             - BRICS collaboration proposal management
             - City health meter visualizations
             - MegaPlan review and approval workflows
             - Budget allocation dashboards
   USED BY : static/pages/government.html

7. central_official.js
   PURPOSE : Powers the Central Official portal:
             - Review and action city-submitted proposals
             - Respond to incoming BRICS joint project requests
             - Status updates for cross-border collaborations
   USED BY : static/pages/central_official.html

8. problem_map_table.js
   PURPOSE : Universal Geospatial Command Map & Data Matrix Controller:
             - Renders Leaflet GIS map with custom RYG status pins
             - Synchronizes side-by-side problem data table with real-time filters
             - Filters by All BRICS Nations, Specific Country, City, RYG Status & Live Search
             - Renders BRICS+ Sovereign Nations Telemetry Matrix table across 11 member states
   USED BY : static/pages/central_official.html, static/pages/city_official.html, static/pages/citizen.html, static/pages/index.html

----------------------------------------------------
  static/css/
----------------------------------------------------

1. styles.css
   PURPOSE : The single global stylesheet for the entire platform.
             Implements the dark glassmorphism design system, all component
             styles (cards, modals, forms, buttons, SLA stepper, maps),
             BRICS gold/dark color palette, and responsive layouts.
   USED BY : All HTML pages via <link rel="stylesheet">.

----------------------------------------------------
  static/img/  — Images
----------------------------------------------------

1. brics_logo.png
   PURPOSE : Official CivicPulse-BRICS logo. Displayed in navbar/headers.
   USED BY : All HTML pages (login.html, citizen.html, etc.)

2. brics_logo_watermark.png
   PURPOSE : Watermarked version of the logo. Used in pitch decks.
   USED BY : Pitch deck presentations.

3. brics_demo.jpg / citizen_demo.jpg / city_demo.jpg / gov_demo.jpg
   PURPOSE : Portal demo screenshot cards shown on the landing index page.
   USED BY : static/pages/index.html

4. img/sectors/  (subdirectory)
   PURPOSE : Sector thumbnail images for the 10+ infrastructure sector
             cards shown on the citizen dashboard (roads, water, power, etc.)
   USED BY : static/js/citizen.js (dynamically loaded into sector cards)

5. img/launch/ (subdirectory)
   PURPOSE : Launch and onboarding screen background images.
   USED BY : static/pages/index.html, login.html

----------------------------------------------------
  static/uploads/  — Runtime User Uploads
----------------------------------------------------

   PURPOSE : Stores all photos uploaded by citizens when reporting
             issues (problem photos) and by city officials when
             resolving complaints (resolution proof photos).
             Files are named with timestamps for uniqueness.
   WRITTEN BY: server.py (file upload handler)
   READ BY  : Served as static files by the web server. URLs are
              stored in civicpulse.db and displayed in complaint cards.
